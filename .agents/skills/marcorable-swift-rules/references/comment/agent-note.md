# 에이전트 주석 표시

에이전트가 **스스로 판단해서** 다는 설명·강조 주석에는 `[AI]` 표시를 붙인다.
표시가 있는 주석은 사용자에게 설명하려고 남긴 임시 메모이고, 표시가 없는 주석은 코드에 남는 주석이다.

```swift
// [AI] typed throws 라서 DataError 로 따로 catch 하지 않아도 된다
} catch {
    return .failure(.data(error))
}

/// [AI] 바코드 이미지 생성이 무거워서 async 로 바꿨다
func barcode(_ barcode: String) async -> CGImage? { ... }
```

사용자는 표시가 있는 주석을 이렇게 처리한다.

- 남길 주석이면 `[AI]` 만 지운다 → 사용자의 주석이 된다
- 필요 없으면 주석째 지운다

## 표시를 붙이지 않는 주석

- 룰이 정한 주석 — `// (Legacy) ... 대체`, `// 임시`, `// FIXME:`, API 의 `/// - Tip: [이름](Swagger 링크)`, 테스트의 `// given` · `// when` · `// then`
- 사용자가 직접 달라고 한 주석 — 사용자가 판단한 소통용 주석이다
- 원래 있던 주석 — 고치거나 지우지 않는다. 내용이 코드와 어긋나면 지우지 말고 알린다

## 알리기

- 작업을 마칠 때 이번에 남긴 `[AI]` 주석을 `파일:줄` 목록으로 알린다
- 커밋하기 전에 남아 있는 `[AI]` 주석을 찾아 알리고, 그대로 커밋할지 묻는다

```bash
git diff --staged -U0 | grep -n '\[AI\]'   # 이번 변경분
grep -rn '\[AI\]' --include='*.swift' .     # 저장소 전체
```

## 하지 않는 것

- 표시 없이 설명 주석 달기 — 사용자가 남길지 판단할 수 없게 된다
- 설명이 길어지면 주석에 다 쓰기 — 한 줄로 요점만 쓰고 자세한 설명은 답변으로 한다
