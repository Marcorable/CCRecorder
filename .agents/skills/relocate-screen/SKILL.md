# 화면 이동

현재 화면이 UIKit인지 SwiftUI인지와 target·모듈 구성을 먼저 확인한다.

## 수행

1. 화면 파일, target membership, import와 진입 경로를 찾는다.
2. 같은 UI 프레임워크와 책임을 가진 기존 화면을 기준으로 새 위치를 정한다.
3. 이력을 보존해 파일을 이동하고 모듈 경계 때문에 필요한 접근 제어와 import만 수정한다.
4. 임시 호환 경로가 필요하면 제거 조건을 표시한다.
5. 이동한 모듈과 앱 타깃을 빌드한다.

## 제외

- UI 프레임워크나 상태 관리 패턴을 함께 바꾸지 않는다.
- 공용 컴포넌트 추출이나 이름 정리를 함께 하지 않는다.
- 커밋을 자동으로 만들지 않는다.

## 결과와 검증

- 기존 진입점에서 같은 화면과 동작에 접근할 수 있다.
- 이동 전후의 사용자 동작이 같고 새 위치에서 빌드된다.
