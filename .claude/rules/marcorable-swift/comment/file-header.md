# 파일 헤더 주석

새 소스 파일 상단에 **파일명·작성자·날짜를 적는 헤더 주석을 넣지 않는다.**

Xcode 가 새 Swift 파일에 자동으로 넣는 다음 형태가 대표적이다.

```swift
//
//  RecordFileStore.swift
//  MyApp
//
//  Created by 홍길동 on 9/23/26.
//
```

파일명은 경로에 이미 드러나고 작성자와 날짜는 git 이력에 남으므로 중복이다.
파일을 옮기거나 여러 사람이 고칠수록 실제 이력과 어긋난다.

## 적용

- 새 파일은 첫 줄을 비우고 둘째 줄부터 시작한다 (`agent-common/marcorable-swift/rules/swift/file-layout.md`)
- 기존 파일을 수정할 때 헤더가 보이면 그 김에 함께 지워도 된다
- 설명 목적의 문서 주석(`///`, `/** */`, docstring)은 해당 없다 — 지우는 건 헤더뿐이다
- 라이선스·저작권 고지처럼 법적으로 필요한 헤더는 예외다
- 레거시 코드 전체를 헤더 제거만을 위해 일괄 수정하지는 않는다. 손대는 파일만 정리한다
- **주변 파일에 헤더가 있어도 따라 하지 않는다.** 내가 예전에 만든 파일에 있어도 마찬가지다. 기존 코드 스타일을 맞추라는 지침보다 이 룰이 우선한다

IDE 가 새 파일에 헤더를 자동으로 붙이면 커밋 전에 지운다.
