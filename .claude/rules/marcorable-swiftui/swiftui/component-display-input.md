# SwiftUI 컴포넌트 표시 입력

여러 화면에서 쓰는 표현 컴포넌트는 원본 Domain Entity 대신 필요한 표시 값과 동작만 받는다.

- 상위 화면이 Domain 값을 `Component.Content` 같은 UI 전용 입력으로 변환한다.
- 표시 입력은 컴포넌트가 실제로 쓰는 문자열, 아이콘 이름, 스타일과 안정적인 ID만 가진다.
- 여러 표시에 공유되는 파생 값은 표시 입력에 둔다.
- 한 번만 쓰는 단순 표현을 옮기기 위해 표시 프로퍼티를 추가하지 않는다.
- 컴포넌트가 화면 전환, 저장이나 Domain 정책을 수행하지 않는다.

한 화면에서만 쓰는 하위 View는 공용 컴포넌트로 승격하지 않는다. 사용 범위와 위치는 `ui-layout.md`, 타입 구성은 `view-composition.md`를 따른다.
