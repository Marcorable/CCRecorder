# 변경 게시

이 스킬은 기존 원자 스킬을 순서대로 적용한다. 커밋 메시지와 PR 형식을 여기서 반복하지 않는다.

## 수행

1. `../commit/SKILL.md`를 읽고 실제 변경 범위를 검토한다.
2. 관련 없는 변경이나 나눠야 할 변경이 있으면 커밋 전에 사용자와 범위를 결정한다.
3. commit 스킬의 확인 절차를 거쳐 커밋한다.
4. `../pr/SKILL.md`를 읽고 베이스 브랜치, 검증 결과와 PR 본문을 확인한다.
5. pr 스킬의 확인 절차를 거쳐 push하고 PR을 생성한다.

커밋이 실패하거나 검증 결과가 PR 본문을 만들기에 부족하면 다음 단계로 진행하지 않는다.

## 완료 조건

- 커밋 범위와 PR 범위가 일치한다.
- 실제로 실행한 검증만 PR 본문에 기록됐다.
- 생성된 커밋과 PR URL을 보고한다.
