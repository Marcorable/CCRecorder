# 화면 상태 정책

상태를 소유하는 타입과 관계없이 다음 의미를 유지한다.

- 목록의 `nil`은 아직 불러오거나 검색하지 않은 상태, `[]`는 완료됐지만 결과가 없는 상태다
- 실패해도 사용자가 보던 이전 결과를 지우지 않는다
- 취소는 오류로 알리지 않는다
- 빈 검색 입력은 검색 전 상태인 `nil`로 되돌린다
- 알럿과 presentation 목적지는 문자열이나 여러 Bool보다 의미가 드러나는 case와 값으로 표현한다

제품 요구사항이 다른 화면은 그 차이를 테스트와 화면별 규칙에 명시한다.
